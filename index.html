eucliMiniAzul

Secuenciador de batería euclidiana · firmware para placa azul (ESP32-S3)

  1. Conecta la placa azul al computador por USB.
  2. Usa Chrome o Edge de escritorio (Web Serial).
  3. Mantén pulsado el botón BOOT de la placa, pulsa Instalar, elige el puerto y sigue aguantando BOOT hasta que termine la barra de progreso.

Tu navegador no soporta Web Serial — usa Chrome/Edge de escritorio. Se necesita HTTPS (o localhost) para acceder al puerto.

Si aparece "Failed to initialize": es normal en esta placa. Repite manteniendo BOOT apretado todo el rato (desde antes de pulsar Instalar hasta el final).

Usa Chrome o Edge de escritorio (Web Serial). Esta página debe abrirse por HTTPS o localhost.

Firmware: ESP32-S3 · 16MB flash · PSRAM habilitada · 4 partes (bootloader 0x0, particiones 0x8000, boot_app0 0xE000, app 0x10000).
