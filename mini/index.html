Use the desktop version of Chrome, Edge or Brave. CLAVE is a Euclidean drum machine (ESP32-S3, red board v3). Before installing, leave the Erase device checkbox unchecked to keep your presets and your saved sound kits.

Firmware (3.0)

1 Connect CLAVE to your computer through the USB-C port J1.

J1 is the data port; J3 only powers the board. Unplug any MIDI device from J1 first.

2 Put CLAVE in download mode: hold shift + play while you plug in the USB cable.

Release both buttons once it is connected. A brand-new board with no firmware doesn't need this step.

3 Press Install and choose the port named “USB JTAG/serial debug unit”.

Your browser doesn't support Web Serial. Use the desktop version of Chrome, Edge or Brave.

This page needs HTTPS (or localhost) to access the USB port.

4 When it finishes, unplug the USB cable and plug it in again to restart CLAVE.

If something goes wrong

The port doesn't show up, or you see “Failed to initialize”: unplug the USB cable, plug it in again while holding shift + play, and press Install again.

The right port is called USB JTAG/serial debug unit.

Close any other page or app that is using CLAVE's USB port (for example Upload Sound Kits in another tab).

Leave Erase device unchecked and your presets and saved sound kits stay in place; ticking it wipes everything.

User manual (PDF, opens in a new tab)

To use CLAVE as a MIDI host (keyboard or pad plugged into J1), power it through J3.

Firmware 3.0 · ESP32-S3 · 16 MB flash · PSRAM · 4 parts (bootloader 0x0, partitions 0x8000, boot_app0 0xE000, app 0x10000).
