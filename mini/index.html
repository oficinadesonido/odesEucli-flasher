eucliMini

Secuenciador de batería euclidiana · firmware para la placa roja v3 (ESP32-S3)

  1. Conecta el eucliMini al computador por el USB-C J1 (el USB de datos; J3 solo alimenta, por ahí no se flashea).
  2. Si había un aparato MIDI enchufado en J1, desconéctalo primero.
  3. Usa Chrome o Edge de escritorio (Web Serial).
  4. Placa nueva (recién ensamblada, sin firmware): pulsa Instalar, elige el puerto y listo — no hay que tocar ningún botón.
  5. Placa que ya tiene firmware: mantén shift + play apretados mientras conectas el USB (o mientras reseteas). La placa entra en modo descarga; suéltalos y pulsa Instalar.

Tu navegador no soporta Web Serial — usa Chrome/Edge de escritorio. Se necesita HTTPS (o localhost) para acceder al puerto.

¿No aparece el puerto o da "Failed to initialize"? Desenchufa el USB, vuelve a enchufarlo manteniendo shift + play, y reintenta. El puerto correcto se identifica como USB JTAG/serial debug unit.

Ya con el firmware instalado (conectado por J1, sin aparato MIDI):

8 kits de batería (4 de fábrica + 4 tuyos, elige con shift + preset); subí y guardá tus kits (quedan al apagar) desde "Subir kit". Para usar la placa como host MIDI (teclado/pad en J1): alimenta por J3 y conecta el aparato en J1.
